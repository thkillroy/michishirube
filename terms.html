利用規約

thkilroy（以下「当サイト」）が提供するアプリ「MICHI-SHIRUBE」（Web 版・Android アプリ。以下「本アプリ」）の利用条件を定めます。本アプリを利用した時点で、本規約に同意したものとみなします。

テスト公開について

本アプリは現在、テスト公開中です。テスト期間中は、全部の機能を無料で提供しており、料金が発生することはありません。無料で利用する場合は、画面に広告の枠が表示されます。Android アプリは準備中です。テスト中のため、予告なく画面・機能・無料で使える範囲が変わったり、不具合が起きたりすることがあります。

地図・検索の提供元

本アプリの地図と検索結果は、OpenStreetMap のデータ（© OpenStreetMap contributors、ODbL）を元にしています。地図は OpenFreeMap（© OpenMapTiles）、場所の検索は Geoapify、住所の検索は Geolonia、道路に沿った経路の計算は FOSSGIS（Valhalla・OSRM）を通して提供されます。場所の検索には回数の上限があります（無料と有料）。

施設の検索のデータは、次のデータを当サイトが加工して作成しています。各データの出典・ライセンスの全文は施設データのライセンスに掲載しています。

  • Overture Maps Foundation の Places データ（CDLA Permissive 2.0。Foursquare が出どころのデータは Apache License 2.0）
  • 「国土数値情報（鉄道データ・高速道路時系列データ・医療機関データ・空港データ）」（国土交通省）を加工して作成（CC BY 4.0 など）。国土交通省が作成したものではありません
  • Wikidata（CC0）

住所の検索には、Geolonia の normalize-japanese-addresses（MIT License）と、デジタル庁「アドレス・ベース・レジストリ」をもとに Geolonia が作成した住所データ（CC BY 4.0）を使っています。

施設の情報（名前・場所・営業の有無など）は毎月1回の更新で、正確性・最新性を保証するものではありません。お出かけ前に、施設の公式の情報もご確認ください。

1. 安全運転について

運転中に画面を注視したり、操作したりしないでください。道路交通法に従い、操作は停車中に行ってください。本アプリの案内よりも、現地の道路標識、信号、交通規制が常に優先されます。

2. 経路と地図の正確性

本アプリが表示する経路、距離、地図の情報は、外部サービスから取得したものであり、正確性・最新性を保証するものではありません。通行止め、一方通行、進入禁止、私有地などが反映されていない場合があります。実際の走行にあたっては、必ず現地の状況を確認してください。

3. アカウント

  • 新規登録の時は、登録したメールアドレスに届く認証番号の入力が必要です。本人が受け取れるメールアドレスで登録してください
  • 登録したパスワードの管理は、利用者の責任で行ってください
  • 他人になりすましての登録は禁止します
  • ユーザー名は、他の利用者から検索される情報です
  • アカウントは、アプリの中からいつでも削除できます。削除すると、保存したデータはすべて消え、元に戻せません（手順と消えるもの）

4. 投稿・公開されるデータ

利用者が「公開」または「フォロワーに公開」に設定したルート、固定ポイント、その名前やメモは、他の利用者が閲覧・保存できる状態になります。以下に該当するものを公開しないでください。

  • 他人の住所、電話番号など、本人の同意なく個人を特定できる情報
  • 他人を誹謗中傷する内容、差別的な内容
  • 違法行為を助長する内容
  • 他人の権利（著作権、商標権、肖像権など）を侵害する内容
  • その他、当サイトが不適切と判断する内容

当サイトは、上記に該当すると判断したデータを、事前の通知なく非公開化または削除する場合があります。

通報とブロック

  • 不適切なルート・固定ポイント・利用者を見つけた時は、アプリの「⚠ 通報」から知らせてください。運営者が確認し、必要に応じて非公開化・削除、アカウントの停止・削除を行います
  • 他の利用者をブロックすると、お互いのルート・固定ポイントが見えなくなり、フォローも解除されます。ブロックされた利用者は、ブロックした利用者をフォローできません
  • いたずらや嫌がらせを目的とした通報は、禁止事項に当たります

SNS への共有

「📤 共有」で SNS に投稿する場合、「公開」または「フォロワーに公開」のものは、名前・共有用の画像・ユーザー名が SNS 上で誰でも見られる状態になります。共有する内容は、利用者の責任で選んでください。共有用の画像に入る地図の出典表示（OpenFreeMap / OpenMapTiles / OpenStreetMap）は、消したり隠したりしないでください。
